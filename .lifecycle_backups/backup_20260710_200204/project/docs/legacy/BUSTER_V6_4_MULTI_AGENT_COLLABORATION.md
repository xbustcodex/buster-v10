# Buster v6.4 Multi-Agent Collaboration

This release gives Buster a real collaboration layer.

## Adds

- CollaborationBlackboard
- AgentMessage
- CollaborationDecision
- DelegationPlanner
- AgentNegotiator
- MultiAgentCollaborationRuntime
- Multi-agent dashboard and widget

## Goal

Agents should not just run in sequence. They should coordinate through a shared blackboard, make decisions, and explain work through the companion runtime.

# Buster v7.0 Living AI Companion

This release starts the external-presence layer.

## Adds

- Skill system
- Skill growth tracking
- Living voice runtime
- Daily rhythm
- Living AI companion runtime
- Living companion dashboard/widget

## Goal

Buster should feel present while you work:

```text
Good morning Adam.
I noticed Android Studio is open.
The ESP32 project is available.
The Builder Agent finished compiling.
All tests are now passing.
I've recorded a new build strategy.
```

The messages are grounded in SDK, mission, intent, and skill events.
